The 6 Academic ERP Modules

Focused strictly on academic evaluation, project documentation, and student details

1. Student Details

Name, register number, roll number, department, course, academic year, batch, email, phone, and student credentials.

2. Final-Year Project Report

Project title, description, technology used, project guide, submission date, and secure PDF report document downloads.

3. Internship Project Report

Company name, domain, internship project title, technology, duration, status, report PDF, and internship certificates.

4. Semester Mark List

Official university semester examination marks, subject codes, subject names, max and obtained marks, and result status.

5. CIA 1 Mark List

Continuous Internal Assessment 1 results with exam dates, configured max marks validation, and result status.

6. CIA 2 / CIA 3 Mark Lists

Separately categorized CIA 2 and CIA 3 evaluations preventing cross-assessment mix-ups with mark boundary checks.
